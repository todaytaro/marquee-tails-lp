# Marquee Tails

Turn 4-8 pet photos into a 60-90 second cinematic AI movie trailer + matching movie poster (POD).

Next.js 16 (App Router) + React 19 + Prisma 7 (PostgreSQL) + Tailwind v4. Heavy generation (fal.ai stills/video, ffmpeg composition) offloads to Trigger.dev; payments via Stripe Checkout; physical prints via Printify.

```bash
npm run dev
```

See `GO-LIVE-RUNBOOK.md` for the production launch checklist.
